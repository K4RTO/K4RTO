### 🌐 About this repo

The portfolio at **[k4rto.com](https://k4rto.com)** is itself the project — a macOS-style desktop running entirely in your browser. Click around: every app is a real React component reading from a tiny IndexedDB-backed filesystem; the Safari app proxies the real web via a Cloudflare Worker; Spotlight does live math; VSCode shows the source of the page you're reading. The source lives in this repo.

**Stack:** Next.js 15 · React 19 · Tailwind CSS 4 · TypeScript 5 · IndexedDB (via `idb`) · static-exported to GitHub Pages · Cloudflare Worker for browser proxy.

**Run locally:**

```bash
git clone https://github.com/K4RTO/K4RTO.git
cd K4RTO
npm install
npm run dev          # http://localhost:3060
```
